# A 股只读数据适配（第一阶段）

基于官方 **v0.7.1**（`c4544913a14ed3df5f1ed7b9e8483270ce20682a`），保留 Apache-2.0 许可证和原有 vendor / LangGraph 架构。仅适配公开研究数据，不接券商账户，不执行买卖。默认关闭；不会替换既有部署，也不需要新增数据 Key。

后续已加入明确可选的腾讯日线源，行情、指标与快照共用国内内核。配置 `ashare_price_vendor="tencent"` 的使用方法、`sz000` 单位校正和当前真实验收结果见 [腾讯适配说明](TENCENT_ZH.md)。下文的东方财富连通记录保留为第一阶段历史记录。

## 启用和免费连通验证

在新的独立环境中安装本分支，Python 3.11 以上：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
# 只读，两只股票，默认截止上海时区的昨天；不加载 .env、不调用 LLM。
python examples/verify_ashare_public.py --start 2026-10-20 --as-of 2026-10-28
```

该脚本只输出连通状态、行数、交易日期和单位，不保存或重分发行情、公告内容。每只股票请求一段日线和最多三页公告，不进行全市场扫描。不要从其他部署复制 `.env`、密钥、日志、缓存或个人持仓。

原工具链通过配置开关启用：

```python
from tradingagents.dataflows.config import run_config
from tradingagents.dataflows.router import route_to_vendor

with run_config({"ashare_data_enabled": True}):
    prices = route_to_vendor("get_stock_data", "603179", "2026-10-20", "2026-10-28")
    announcements = route_to_vendor("get_news", "000001.SZ", "2026-10-01", "2026-10-28")
```

正式研究运行也可设置 `TRADINGAGENTS_ASHARE_DATA_ENABLED=true`，并使用原有 LLM 配置；**正式模型运行可能产生模型费用**，以上免费验证不运行模型。建议仅选 `market,news,fundamentals`，中文输出设置为 `Chinese`。A 股模式会强制沪深标的使用国内 vendor，包括 `get_verified_market_snapshot`，不会因数据源失败退回 SEC / Yahoo；非沪深个股仍走上游配置。此模式下全局新闻、宏观和预测市场工具明确返回不可用。

## 实际支持范围

| 能力 | 第一阶段行为 |
| --- | --- |
| 代码识别 | 沪主板 `600/601/603/605`、科创板 `688`；深主板 `000/001/002/003`、创业板 `300/301`。接受六位代码、`SH`/`SZ` 前缀、`.SH`/`.SS`/`.SZ` 后缀，核对前后缀冲突。识别命名空间不代表保证已上市。 |
| 日 OHLCV、成交额 | 东方财富公开日线 `klt=101,fqt=0`，日期区间包含两端。价格为人民币元/股；源成交量为**手**，输出保留 `VolumeLots`，`Volume=VolumeLots×100` 为股；`Amount` 保留**元**，绝不按万元放大。源手数可能经行情商舍入，不能据此声称逐笔精确股数。 |
| 复权 | 仅不复权。拒绝 qfq/hfq，避免将今天复权因子应用到历史回测。除权、除息、拆并股会形成缺口，不把未复权价格变化称为投资收益。 |
| 交易日与时区 | `Asia/Shanghai`，上海/深圳普通股票共用常规开市日历；采用 `exchange-calendars` 的 XSHG 明确覆盖区间，超出覆盖返回不可用。周末调休工作日不等于证券开市。当前安装 4.13.2 的覆盖上限为 2026-12-31；以后需要更新日历包。 |
| 当前日线 | 数据源缺少可靠“最终收盘”标志，因此**上海时区当天整根日线均不进入输出**，15:00 后也等待下一自然日；当日分析使用最近已完成交易日并标明实际日期。盘中/最新价研究未实现。 |
| 缺失与停牌 | 不补零、不前向填充。若最新行落后于应有交易日，返回不可用并指出可能停牌/覆盖不足；尚不能自动区分真实停牌和供应商遗漏。不拒绝所有内部缺口，也不声称窗口内数据完整。 |
| 指标与核验快照 | 同一国内不复权日线计算 SMA/EMA、MACD、RSI、BOLL、ATR、VWMA、MFI；不足最小预热行数显示 N/A。不会为休市日造一行指标；除权事件影响未消除。 |
| 公司公告 / 定期报告索引 | 东方财富/Choice 单公司公告索引，包含原公告详情链接、名义公告日期、可用时间和从明确标题解析的报告期。`get_news` 返回的只是公告索引，**不是国内综合新闻**；`get_fundamentals` 返回定期报告索引。 |
| 三张财务报表 | 仅返回候选报告索引；数值表格、估值、TTM、历史版本数字均显式不可用。不会由标题推算营收、利润或资产。 |

不支持 B 股、基金/ETF、债券、北交所、CDR、指数，以及未列明代码前缀。`000001` 指深圳个股，`000001.SS` 为上海指数，不会被误认成平安银行。国内舆情（股吧/雪球/微博等）、龙虎榜、资金流、主力/机构账户、北向流、交易制度模拟、涨跌停/停牌明细、除权因子、盘中行情、国内宏观信息均未实现。选择 sentiment 分析师时直接生成“证据不可用”，不调用 StockTwits/Reddit，也不把缺证据记为中性。

本阶段关闭 A 股自动收益结算/alpha 评分：上游的收益通路仍依赖 Yahoo 且需要复权及基准支持，不能用未复权个股数据伪造策略表现。已有待结算条目会报告数据不可用并保留待定，不调用反思 LLM。此分支不对收益或策略有效性作保证。

## 披露时间与历史边界

报告期结束不代表财报已公开。例如 2025 年报在 2026-04-01 公告，2026-03-31 的分析不能读取其索引条目。接口会再次本地过滤，不仅信任服务器的起止参数：

1. 名义公告日期、`display_time` 与 `eiTime` 按上海时区解析，使用其较晚时点；只有名义日期时保守延后至次日 00:00。字段无法解析则排除并给出排除数量。
2. 历史日期截止当日上海时区 23:59:59；今天截止真实读取时刻，不混入晚间公告。过滤未来报告期和其他公司的混入记录。
3. 定期报告期只从明确的年度、半年度、第一/第三季度报告标题提取；未知报告期不猜测。年度/季度频率明确校验，季度索引不把年度报告伪装成单独 Q4。
4. 最多三页、每页 100 条，分页受限或短页会显示 partial。空列表、被过滤列表及失败**不等于无公告、无负面新闻或无风险**。

这是**当前可查询索引按时间过滤**，不是历史快照服务：无法恢复后来删除的公告、同一记录后续修改却未更新时间的内容，或证明历史完整覆盖。来源更正也可能改变历史日线。不提供“完全按当时所见”的财务数据库或回测结果。需要严格可复现回测时，应获得合规授权的版本化历史数据后再实现。

HTTP 超时 15 秒；重定向、401/403/429、错误 JSON 和接口结构变化均返回不可用，不重试，不轮换 IP，不伪造浏览器身份，不读取 cookies，不绕登录、反爬或付费限制。所有数据输出标明来源与读取时刻。巨潮公司查询在 2026-10-29 本机小规模测试中返回 HTTP 500，第一阶段未声称直连巨潮或交易所机器接口已完成。

2026-10-29 在独立环境中对 `603179` 和 `000001` 请求 2026-10-20..2026-10-28，首次公开日线均成功返回 7 行，最新日期 2026-10-28。随后 17:09 上海时间用已实现的 vendor 链复验，两个行情请求均在代理连接阶段被远端断开（ProxyError/RemoteDisconnected），均正确返回 DATA_UNAVAILABLE，未尝试绕过；两只股票的公告接口仍可达。因此初次行情连通成功，但本机国内行情端当前并不稳定，不能承诺即刻全链路持续可用。此记录不代表长期可用性或独立审计数据质量，未调用付费 LLM，未计算收益。
